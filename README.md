# Ecommerce Sales Dashboard using Power BI

The goal of the E-commerce Sales Dashboards project was to deliver in-depth insights into online sales performance by creating interactive, visually engaging dashboards with Power BI. The project concentrated on tracking and analyzing important metrics, including profit, number of orders, customer demographics, product performance, and sales patterns. By utilizing data from the e-commerce platform, the dashboards helped stakeholders make informed, data-driven decisions, uncover opportunities for growth, and assess the impact of marketing efforts.
